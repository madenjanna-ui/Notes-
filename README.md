# notes@

Локальное PWA-приложение заметок для iPhone с тёмным стеклянным интерфейсом.

## Возможности
- Несколько независимых заметок.
- Цветные сворачиваемые разделы с отдельным текстом.
- Изменение названия и цвета каждого раздела.
- Поиск по заголовкам и содержимому.
- Автосохранение в `localStorage` на текущем устройстве.
- Экспорт и импорт резервной копии JSON.
- PWA manifest, иконки и service worker для офлайн-запуска.

## Публикация
PWA требует HTTPS (например, GitHub Pages). Загрузите содержимое папки в корень репозитория и включите GitHub Pages для ветки/папки публикации.

## Установка на iPhone
1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Подтвердите добавление.

## Важно
Данные хранятся только в локальном хранилище браузера на устройстве. Они не синхронизируются автоматически между устройствами. Экспортируйте JSON-копию регулярно. Очистка данных Safari может удалить локальные заметки.
